# ZIET Mumbai – KVS CPD Management Portal

A responsive CPD management web application for recording staff profiles, CPD activities, approved learning hours, annual targets, progress reports and certificate references.

## Included modules
- Dashboard with staff, activity, hours and certificate summaries
- Staff profiles with Teaching / Non-Teaching categories
- CPD activity register with dates, approved hours and evidence references
- Individual progress against annual targets
- Certificate register and link to the separate ZIET CPD Certificate Generator
- Guidelines and circular reference links
- CPD hours calculator
- CSV exports and JSON backup / restore

## Publish with GitHub Pages
1. Open this repository's **Settings** tab.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**, then click **Save**.
5. Wait for GitHub Pages to finish deployment. The expected site address is:
   https://taprimaryzietmumbai-kjrd.github.io/ZIET-Mumbai-KVS-CPD-Management-Portal/

## Important data and privacy note
This version stores records in the browser's local storage. Data does not automatically synchronize between users, computers or browsers. It is a working single-browser prototype, not yet a central institutional database. Download JSON backups regularly. Before collecting official staff records across multiple schools or regions, connect a secure authenticated backend and establish appropriate access controls and data governance.

## CPD targets
The initial planning benchmarks are 50 hours for Teaching Staff and 30 hours for Non-Teaching Staff. These values are editable in Settings. Confirm current applicable KVS / CBSE / NCERT directions before official implementation or reporting.
